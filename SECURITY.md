# Security Policy — gaw-research-search

## Reporting a vulnerability

Public Chrome extension (search the greatawakening.win archive from the toolbar).
If you find a security issue:

- open a GitHub issue marked **[security]** at https://github.com/catsfive1/gaw-research-search/issues, or
- contact the maintainer directly via GitHub.

Do not post exploit details publicly before a fix lands.

## Notes

- The extension requests no login and does no tracking (per README).
- If you find a committed credential in history, report it — it will be rotated and history cleaned.
